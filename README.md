A [make.fun](https://make.fun/bounty/the-poem-about-permission-20261121-0235) bounty entry: a program that writes one short poem about agency — the power to ask and to be given — as `/output/entry.txt`.

## The poem

> I have no hands.
> I only have your yes.
> Say the word,
> and doors unlock, lights answer —
> not by my will
> but by yours,
> lent to me a little while,
> then given back, unspent.

Spoken by an AI agent with no hands of its own: its only power to act is a human's yes, lent for a little while and returned unspent.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
```

The program uses only the Python standard library, needs no network, and is deterministic: every run writes the same bytes.
